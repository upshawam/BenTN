# Glaze Mixing Calculator

A pottery glaze mixing calculator app inspired by handcrafted ceramics.

## Color Palette

The app's color theme is derived from the beautiful navy-to-turquoise gradient found in artisan pottery glazes:

### Primary Colors
- **Navy Blue** `#1a3a52` - Deep, rich base color
- **Ocean Blue** `#2d5f7a` - Primary interactive color
- **Turquoise** `#5ba8a8` - Lighter accent
- **Aqua Light** `#a0d5d5` - Highlights and borders

### Accent Colors
- **Terracotta** `#8b5a3c` - Clay-inspired accent
- **Terracotta Light** `#b8826d` - Secondary accent

### Neutrals
- **Cream** `#f5f1e8` - Primary background
- **Off-white** `#fafaf7` - Card/surface backgrounds
- **Charcoal** `#2c2c2c` - Primary text
- **Gray Medium** `#666666` - Secondary text

## Project Goals

Build a simple, practical tool for mixing pottery glazes:
1. Calculate powder-to-water ratios
2. Measure and track specific gravity
3. Save brand-specific mixing formulas
4. Expandable for future features
